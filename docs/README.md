# متجر سندرين بيوتي - مشروع متجر إلكتروني

## 📋 وصف المشروع
متجر إلكتروني حديث مبني باستخدام أحدث التقنيات، مصمم لتحقيق أفضل تجربة مستخدم وأداء عالي.

## 🛠️ التقنيات المستخدمة
- **Next.js 16.2.3** - مع Turbopack لأداء فائق
- **React 19** - المكونات والتفاعل
- **TypeScript** - أمان الأنواع وقابلية الصيانة
- **Tailwind CSS 4** - التصميم والأنماط
- **Jest** - الاختبارات الآلية

## 🚀 كيفية التشغيل

### 1. التثبيت
```bash
npm install
```

### 2. تشغيل بيئة التطوير
```bash
npm run dev
```

المشروع سيعمل على: `http://localhost:3000`

### 3. بناء الإنتاج
```bash
npm run build
```

### 4. تشغيل الإنتاج
```bash
npm run start
```

### 5. تشغيل الاختبارات
```bash
npm run test
```

### 6. فحص الجودة والأنماط
```bash
npm run lint
```

## 📂 هيكل المشروع المحسن

sendreen-store/

```env

CLOUDINARY_UPLOAD_PRESET=your_upload_preset
NEXT_PUBLIC_ADMIN_WHATSAPP=201158897041
```
