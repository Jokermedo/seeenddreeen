# دليل النشر - سندرين بيوتي

## 🚀 إرشادات النشر السريع

### المتطلبات الأساسية
- Node.js 20 أو أحدث
- حساب على Vercel (موصى به) أو أي خادم يدعم Next.js
- بيانات اعتماد Cloudinary
- رقم واتساب للإدارة

---

## 📋 متغيرات البيئة المطلوبة

| المتغير | الوصف | القيمة الافتراضية |
|---|---|---|
| `CLOUDINARY_CLOUD_NAME` | اسم حساب Cloudinary | `dnfjt8o5e` |
| `CLOUDINARY_API_KEY` | مفتاح API لـ Cloudinary | موجود مسبقاً |
| `CLOUDINARY_API_SECRET` | السر الخاص بـ Cloudinary | موجود مسبقاً |
| `NEXT_PUBLIC_CLOUDINARY_CLOUD_NAME` | نفس الاسم العام | `dnfjt8o5e` |
| `NEXT_PUBLIC_CLOUDINARY_UPLOAD_PRESET` | إعداد الرفع | `ml_default` |
| `NEXT_PUBLIC_ADMIN_WHATSAPP` | رقم واتساب الإدارة | `201158897041` |

---

## 🛠️ الخطوات للنشر على Vercel (الموصى به)

1. اربط المستودع بـ Vercel
2. أضف جميع متغيرات البيئة أعلاه
3. اضبط إعدادات البناء:
   - أمر البناء: `npm run build`
   - مجلد الإخراج: `.next`
   - إصدار Node.js: 20.x

4. انقر على نشر - سيكتمل النشر خلال 2-3 دقائق

---

## 🧪 التحقق بعد النشر

بعد اكتمال النشر، قم بالتحقق من:
- ✅ الصفحة الرئيسية تتحمل بشكل صحيح
- ✅ نموذج الطلب يظهر بشكل كامل
- ✅ التحقق من البيانات يعمل
- ✅ زر إرسال الطلب يعيد توجيه لواتساب
- ✅ رفع الصورة يعمل بشكل صحيح
